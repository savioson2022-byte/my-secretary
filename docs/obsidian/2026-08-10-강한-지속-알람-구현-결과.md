# 나의 비서 강한 지속 알람 구현 결과

- 작업일: 2026-08-10
- 범위: 제안 항목 중 4번 Apple Critical Alerts 제외

## 구현 내용

1. iOS 26 이상에서 AlarmKit 시스템 알람을 예약·취소하는 Capacitor 플러그인을 추가했다.
2. iOS 25 이하와 웹/PWA는 기존 로컬 알림, 서버 푸시, 앱 전체 화면 알람을 그대로 사용한다.
3. 지속 알람은 기본 간격 1분 기준 `0, 1, 3, 5, 7분`처럼 점진적으로 재알림한다.
4. 알림의 확인, 다시 알림, 오늘 끄기를 서버의 `persistent_alarm_acknowledgements`에 기록한다.
5. 알림 본문 탭은 확인으로 처리하지 않고 전체 화면 알람으로 이어진다. 실제 버튼 동작만 확인 완료로 기록한다.
6. 사용자가 확인하거나 미루면 같은 그룹의 로컬 알림과 AlarmKit 알람을 함께 취소한다.
7. 기존 위치 기반 알림 재계산 결과가 바뀌면 이전 시스템 알람을 취소하고 새 출발 시각으로 다시 예약한다.
8. 설정 화면에 시스템 알람 권한 확인 버튼과 AlarmKit을 포함한 지속 알람 테스트를 추가했다.

## 지원 범위와 제한

- AlarmKit 시스템 알람: iOS 26 이상
- iOS 25 이하: 반복 로컬 알림 + 서버 푸시 + 앱 내부 지속 알람
- 웹/PWA: 브라우저와 운영체제 정책상 소리 지속 재생을 보장할 수 없으므로 서버 푸시와 앱 내부 알람을 사용
- Critical Alerts 권한과 기능은 요청대로 포함하지 않음
- 실제 기기에서 화면 잠금, 무음 모드, 집중 모드, 앱 강제 종료 상태 테스트가 추가로 필요

## 실제 기기 확인 절차

1. 설정 → 알림 설정 → 강한 알람 권한 확인을 누른다.
2. 지속 알람 테스트를 누른 직후 화면을 잠근다.
3. 로컬 알림과 iOS 시스템 알람이 각각 울리는지 확인한다.
4. 알림 본문 탭만 했을 때 전체 화면 알람이 계속되는지 확인한다.
5. 지금 시작, 다시 알림, 오늘 끄기 각각으로 이후 알림이 취소되는지 확인한다.
6. 위치가 있는 일정의 출발 시간이 바뀌었을 때 이전 알람 대신 새 시각에 울리는지 확인한다.
