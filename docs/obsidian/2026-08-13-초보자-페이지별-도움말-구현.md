# 나의 비서 초보자 도움말 구현

- 작업일: 2026-08-13
- 목적: 처음 사용하는 사람이 각 기능의 의미와 사용 순서를 앱 안에서 바로 확인할 수 있게 한다.

## 구현 내용

1. 주요 화면 상단에 `?` 도움말 버튼 추가
   - 홈: 시간 작업의 개념, 일정과의 차이, 입력·승인·자동 배치 흐름
   - 주간/월간 캘린더, 단기 일정, 일정 관리
   - 구매 준비: 쿠팡 주문 메일의 Gmail/네이버 연결 순서
   - 기록, 위임, 장소, 설정 및 설정 하위 화면
2. 모바일에서는 하단 시트, 큰 화면에서는 중앙 팝업 형태로 표시
3. ESC, 닫기, 배경 선택으로 닫을 수 있으며 스크린리더용 이름과 대화상자 속성 적용
4. 첫 회원가입 계정에 시간 작업 안내를 한 번 자동 표시
   - 이메일 회원가입 시 계정 메타데이터에 최초 안내 대기 상태 기록
   - 소셜 가입은 가입 시각이 30분 이내인 신규 계정만 최초 안내 대상으로 판별
   - 개인정보/AI 동의창을 먼저 처리한 뒤 안내하여 팝업 중첩 방지
   - 확인 시 Supabase 계정 메타데이터와 기기 로컬 저장소에 완료 상태를 저장
   - 기존 계정에는 자동 표시하지 않으며 홈의 `?` 버튼으로 언제든 확인 가능

## 검증 결과

- `npm run lint`: 통과, 기존 경고만 유지
- `npm run build`: 성공, 54개 페이지 생성
- `npx tsc --noEmit`: 성공
- `git diff --check`: 성공
- 최초 안내 판별: 신규/기존/확인 완료/명시적 대기 4가지 조건 확인
- 로컬 실제 화면:
  - 홈 시간 작업 도움말 열기·닫기 정상
  - 주간 캘린더 도움말 버튼 노출 정상
  - 구매 준비의 쿠팡 메일 연결 도움말 버튼 노출 정상
  - 브라우저 콘솔 오류 없음

## 운영 참고

- 온보딩 확인 여부는 보안 권한 판단에 사용하지 않는 사용자 메타데이터다.
- 새 데이터베이스 테이블이나 마이그레이션은 추가하지 않았다.
- 기존의 미추적 iOS 파일 `ios/App/App/config 2.xml`은 변경하지 않았다.
