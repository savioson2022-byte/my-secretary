# 나의 비서: 음성 검토함·예약 위임·강한 알람 개선

- 작업일: 2026-08-13
- 프로젝트: 나의 비서(My Secretary)
- 범위: 음성 기록 검토함 삭제, 예약 위임, iPhone 강한 알람 호환성

## 1. 음성 기록 검토함 삭제

- 승인 전과 승인 후 목록 모두에 삭제 기능을 추가했다.
- 실수 방지를 위해 `삭제` 후 `정말 삭제`를 한 번 더 눌러야 삭제된다.
- 승인 전 기록을 삭제하면 해당 검토 초안만 제거된다.
- 승인 후 기록을 삭제해도 이미 저장된 일정·시간 작업·메모 원본은 유지되며 검토 이력만 제거된다.
- 현재 수정 중인 기록을 삭제하면 열려 있던 분류 결과도 함께 닫힌다.

## 2. 예약 위임

- 위임 화면에서 재구매 후보와 예약 요청을 각각 확인할 수 있게 정리했다.
- 네이버·카카오 장소 검색 결과에서 예약 장소를 고를 수 있다.
- 날짜, 시간, 예상 소요 시간, 인원, 메모를 입력할 수 있다.
- 루틴과 기존 단기 일정의 빈 시간을 계산해 가능한 시간대 3개를 추천한다.
- 충돌하는 시간을 직접 선택하면 저장을 막고 사유를 안내한다.
- 네이버 플레이스 예약 화면을 연 뒤 실제 예약 완료를 확인해야 앱 일정 저장 버튼이 활성화된다.
- 저장된 예약은 단기 일정과 장소에 함께 반영되어 장소 기반 이동 알림이 사용할 수 있다.

> 현재 네이버 공개 Local Search API는 장소 검색을 제공하지만, 외부 업체 예약을 앱이 임의로 확정하는 공개 API는 연결되어 있지 않다. 따라서 예약 확정은 네이버 플레이스에서 사용자가 완료하고, 앱은 시간 추천·충돌 검사·일정 저장을 담당한다.

## 3. 강한 알람

### 원인

- 연결한 기기는 iPhone 14 Pro, iOS 26.5.2로 AlarmKit 지원 조건을 충족했다.
- 기기에 설치되어 있던 나의 비서 앱은 빌드 1이었다.
- AlarmKit 브리지는 그 이후 추가되었기 때문에 이전 앱이 플러그인을 찾지 못했고, 이를 단순히 `기기 미지원`으로 표시하고 있었다.
- 앱이 열린 상태에서 반복 소리와 진동을 담당하는 `AlarmPulsePlugin`도 Xcode 프로젝트에는 있었지만 Capacitor 브리지에 등록되지 않아 실제 호출되지 않았다.

### 수정

- iOS 26 이상: Apple AlarmKit 시스템 알람을 사용한다.
- iOS 15~25: 시간 민감 알림을 우선 사용하고 기존 반복 알림을 이어서 예약한다.
- 앱이 열린 상태: 사용자가 확인할 때까지 강한 소리와 진동을 반복한다.
- 오래된 앱, 브리지 오류, 웹/PWA 접속을 각각 다른 상태로 구분해 안내한다.
- 날짜 문자열의 소수점 초 유무를 모두 처리하도록 iOS 파서를 보강했다.
- 동일 시점에 AlarmKit과 첫 일반 알림이 겹치지 않게 중복 예약을 줄였다.
- iOS 빌드 번호를 5로 올렸다.

### 실기기 적용

- 개발자 서명으로 iPhone용 빌드 5 생성 성공.
- 연결된 iPhone에 `app.mysecretary.mobile` 빌드 5 설치 성공.
- 설치 후 기기 조회에서 Version 1.0 / Bundle Version 5 확인.
- 최초 실행 후 앱의 `설정 → 알림 → 강한 알람 권한 확인`에서 AlarmKit 권한을 허용해야 한다.

## 운영 시 확인

- AlarmKit 권한은 일반 알림 권한과 별도이므로 새 빌드 최초 실행 때 허용해야 한다.
- Apple의 Critical Alerts 권한은 별도 심사·entitlement가 필요한 기능이며 이번 구현에 포함하지 않았다.
- 실기기 빌드 5는 개발 설치본이다. 일반 사용자에게 제공하려면 App Store Connect/TestFlight에 새 네이티브 빌드를 올려야 한다.
