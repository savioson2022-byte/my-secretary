# PC·모바일 화면 최적화

## 설계
같은 일정과 기록, 저장 로직을 사용하면서 화면 폭에 따라 PC와 모바일 레이아웃을 분리한다. 별도 앱이나 데이터 사본을 만들지 않는다.

| 화면 | 메뉴 | 작업 영역 |
| --- | --- | --- |
| 모바일: 768px 미만 | 하단 5개 메뉴 | 한 열, 터치 중심 |
| 태블릿·좁은 창: 768~1023px | 104px 왼쪽 메뉴 | 가용 폭 전체 활용 |
| PC: 1024px 이상 | 216px 고정 사이드바 | 일정 입력과 목록을 두 열로 배치 |
| 넓은 PC: 1536px 이상 | 동일 | 홈의 기록 패널도 옆으로 배치 |

## 변경 사항
- 홈·캘린더·기록·일정관리·설정 바로가기 통일.
- 페이지별 최대 폭과 사이드바 여백 충돌 해결.
- 일정관리에서 왼쪽 입력, 오른쪽 단기 일정 및 정기 수업 목록 표시.
- 모바일 하단 메뉴를 화면 전체 폭으로 사용하고 안전 영역 반영.
- 터치 기기 버튼 최소 높이 44px, 모바일 입력 글자 16px 적용.
- 화면 확대 제한 해제, 키보드 포커스 강조, 현재 메뉴 접근성 표시.
- 홈의 가짜 9:41 시계 삭제, PC에서 부자연스럽던 휴대폰 입력 안내 수정.
- 이전 작업의 수업별 요일·시간 수정 기능 유지.

## 검증
- 프로덕션 빌드 성공: 57개 경로. 이후 화면 여백 CSS를 보완하고 로컬 미리보기에서 재확인.
- TypeScript 검사와 diff 공백 검사 통과.
- 기존 일정 수정 회귀 검사 8개 통과.
- lint: 기존 React Hook 의존성 경고 10개, 오류 없음.
- 1280px 로컬 브라우저에서 홈과 일정관리 화면 렌더링, 메뉴 위치 및 두 열 배치 확인.
- 실제 모바일 기기 및 로그인한 계정의 동작은 미검증. 모바일 키보드·안전 영역·가로 회전은 실기기 확인 필요.
