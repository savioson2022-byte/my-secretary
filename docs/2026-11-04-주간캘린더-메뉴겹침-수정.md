# 문제와 원인
맥북 주간 캘린더에서 왼쪽 메뉴가 제목과 월요일 열 위를 가렸다. phone-shell의 backdrop-filter가 내부 fixed 메뉴의 기준 영역을 만들어, 메뉴가 창이 아닌 카드 내부에 고정됐다.

# 수정
- 공통 메뉴를 React Portal로 document.body에 렌더링해 카드의 필터·변형·잘림 영향을 제거했다.
- 서버 렌더링과 최초 클라이언트 렌더링은 동일하게 처리한 뒤 마운트 시 메뉴를 표시한다.
- 주간 및 단기 일정의 PC 화면에서 휴대폰 테두리·블러·추가 여백을 제거했다.
- 가짜 9:41 시계를 삭제했다.
- 좁은 화면에서 헤더 버튼 줄바꿈을 허용했다.

# 검증
- 프로덕션 빌드 성공: 57개 경로.
- 타입 검사와 diff 공백 검사 통과. 기존 Hook 의존성 경고만 유지.
- 로컬 1280×720 주간 화면에서 메뉴와 제목·시간축·월요일 열이 겹치지 않음을 스크린샷으로 확인.
- 390×844 모바일에서 하단 메뉴가 창 바닥에 고정되고 하루 일정 화면이 표시됨을 확인.
- 검증용 화면 크기 설정 복원.
- 실제 일정 데이터 변경 및 DB 변경 없음.
