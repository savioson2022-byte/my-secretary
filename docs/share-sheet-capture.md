# 어디서든 담기 (공유 시트 · 잠금화면)

앱을 열지 않고 아무 앱에서나 텍스트를 나의 비서에 담는 방법.

## 왜 확장 프로그램을 안 만들었나

iOS 공유 익스텐션과 위젯은 각각 **Xcode 타겟을 새로 만들어야** 하고, 앱과 데이터를
주고받으려면 App Group 권한을 Apple Developer 계정에서 켜고 프로비저닝 프로파일을
다시 발급해야 한다. 그것 없이도 같은 결과를 낼 수 있어서 딥링크로 먼저 해결했다.

```
mysecretary://capture?capture=<담을 내용>
```

이 주소로 앱을 열면 **화면을 거치지 않고 즉시 저장**된다. 분류는 뒤에서 돈다.
웹에서도 `https://my-secretary-remote.vercel.app/?capture=<내용>`으로 같게 동작한다.

한글과 공백은 인코딩하지 않고 그대로 넣어도 된다. 앱이 URL을 만들지 못하면
퍼센트 인코딩해서 다시 시도한다.

> Safari 주소창으로는 테스트하지 말 것. 공백이 있으면 Safari가 주소가 아니라
> 검색어로 처리한다. 테스트는 공백 없는 `mysecretary://capture?capture=test`로 하거나
> 단축어로 한다.

## 단축어 만들기 (한 번만, 3분)

동작 **세 개**다. 가운데 `텍스트` 동작이 핵심인데, 이유는 아래에 있다.

1. 단축어 앱 → `+` → 새 단축어
2. 아래 **ⓘ** → **공유 시트에 표시** 켜기
   - `받는 항목`에서 **텍스트**와 **URL**만 남기고 나머지는 끈다
3. **동작 추가** → `입력에서 텍스트` 검색 → **입력에서 텍스트 가져오기** 선택
   - 입력이 **단축어 입력**인지 확인한다 (보통 자동으로 들어간다)
4. **동작 추가** → `URL 열기` 선택
   - 값에 `mysecretary://capture?capture=` 를 입력하고,
     맨 끝에 변수 버튼으로 3번에서 만든 **텍스트**를 붙인다
5. 위쪽 이름을 눌러 `나의 비서에 담기`로 바꾼다

최종 모양:

```
1. 공유 시트에서 받기
2. 입력에서 텍스트 가져오기  ← [단축어 입력]
3. mysecretary://capture?capture=[텍스트] 열기
```

### `입력에서 텍스트 가져오기`가 필요한 이유

공유되는 것의 형식이 상황마다 다르다.

- 기사 **링크**를 공유하면 URL로 온다
- 기사 **본문을 선택**해서 공유하면 웹페이지 객체와 텍스트가 섞여서 온다
- 구글 뉴스 등에서는 **리치 텍스트**로 온다

`단축어 입력`을 그대로 쓰면 형식에 따라 아래처럼 실패한다.

> 단축어가 리치 텍스트를 URL로 변환할 수 없기 때문에 URL 열기에 실패했습니다.

또는 앱까지는 도달하는데 내용이 비어서 이렇게 뜬다.

> 담기 요청은 왔는데 내용이 비어 있었어요.

`입력에서 텍스트 가져오기`는 어떤 형식이 오든 텍스트만 뽑아내므로 세 경우가 모두 해결된다.
그래도 비면 `공유 시트에서 받기`의 받는 항목을 **텍스트만** 남긴다. iOS가 넘겨주기 전에
평문으로 바꿔준다.

### 담겼는지 확인하는 법

담기 딥링크로 들어오면 홈 화면 맨 위에 초록 배너가 뜬다.

| 배너 | 뜻 |
| --- | --- |
| `담았어요: ○○○` | 정상. 담긴 내용까지 그대로 보인다 |
| `내용이 비어 있었어요` | 딥링크는 왔지만 단축어가 텍스트를 못 넘겼다 |
| 배너 없음 | 딥링크가 웹까지 도달하지 못했다 |

### 잘 됐는지 확인

Safari에서 아무 문장이나 길게 눌러 선택 → 공유 → `나의 비서에 담기`.
앱이 열리면서 그 문장이 저장되면 성공이다.

## 쓰는 곳

| 위치 | 방법 |
| --- | --- |
| 아무 앱의 공유 버튼 | 공유 → `나의 비서에 담기` |
| 잠금화면 | 잠금화면 편집 → 위젯 추가 → 단축어 → `나의 비서에 담기` |
| 홈 화면 | 위젯 추가 → 단축어 |
| 동작 버튼 (iPhone 15 Pro 이상) | 설정 → 동작 버튼 → 단축어 |
| 뒷면 탭 | 설정 → 손쉬운 사용 → 터치 → 뒷면 탭 |
| Siri | "나의 비서에 담기" |

## 확인

담은 뒤 앱을 열면 홈 목록 맨 위에 있어야 한다.
`설정 → 알림과 알람`이 아니라 **홈 화면**에서 확인한다.

## 나중에 만들 것

진짜 공유 익스텐션과 위젯은 다음이 준비되면 만든다.

1. Apple Developer 계정의 App ID에서 **App Groups** 켜기
2. 프로비저닝 프로파일 재발급
3. Xcode에서 Widget Extension / Share Extension 타겟 추가

위젯은 "지금 할 것 하나"를 잠금화면에 띄우는 용도라 그때 가치가 커진다.
지금 단계에서는 담는 것이 먼저다.
