# 일정관리 개선

## 요청과 개선
고1 2반의 화요일 수업을 유지하면서 목요일 수업만 일요일로 옮기는 작업을 쉽게 만든다.

- 정기 일정 묶음 안에서 개별 수업을 요일별로 표시한다.
- 각 수업의 ‘요일·시간 변경’에서 요일과 시작·종료 시간을 바꾼다.
- 변경 전후를 확인하고 ‘이 수업만 저장’을 누른다. 취소하면 저장되지 않는다.
- 다른 수업은 수정하지 않으며 대상 수업의 ID, 장소, 메모, 기간, 이동수단, 색상, 생성일, 취소 날짜를 보존한다.
- 제목 검색 및 ‘기존 수업 찾기·수정’ 바로가기를 추가했다.
- 새 일정 입력에 ‘시간대 복사’를 추가했다. 시간은 복사하고 요일은 새로 선택해 실수로 중복 등록하는 일을 줄인다.
- 빈 시간, 잘못된 시간 순서, 동일 제목·요일·시간·겹치는 기간의 중복 수업, 편집 도중 외부에서 바뀐 데이터를 검사한다.

## 사용 예시
1. 일정 관리 → 기존 수업 찾기·수정
2. ‘고1 2반’ 검색
3. 목요일 수업 → 요일·시간 변경
4. 일요일 선택 → 변경 내용 확인 → 이 수업만 저장
5. 화요일 수업은 유지되고 목요일 수업만 일요일로 바뀐다.

## 적용 범위
기존 반복 기간 전체의 요일을 변경한다. 특정 날짜 한 번만 이동하거나 특정 날짜 이후부터 분리하는 기능은 이번 변경 범위에 포함하지 않는다. 취소 기록은 원래 날짜에 남으며 새 요일로 자동 이동하지 않는다. 기존 묶음 편집 기능은 그대로다.

## 검증
- 회귀 검사 8개 통과: 다른 수업 불변, 대상 필드 보존, 빈 시간/역전 시간 거부, 중복 거부, 삭제/외부 변경 감지, 기간이 겹치지 않는 수업 허용.
- lint 통과: 기존 Hook 의존성 경고 10개 유지.
- 프로덕션 빌드 성공: 57개 페이지 생성.
- 실제 로그인 계정 및 휴대폰 UI 조작은 미검증.
